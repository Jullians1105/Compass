RF y no RF
Tabla 1 Requerimiento funcional 1
RF-01 Autenticación de usuarios
Descripción	El sistema debe permitir que los usuarios accedan mediante un proceso de autenticación con credenciales válidas.
Actor	Usuario
Prioridad	Alta
Entrada	Email o usuario, contraseña
Salida	Token de sesión (JWT), ID de usuario, nombre completo, rol asignado, lista de permisos, fecha de expiración del token

Tabla 2 Requerimiento funcional 2
RF-02 Cierre de sesión del sistema
Descripción	El sistema debe permitir que los usuarios cierren sesión de manera segura para finalizar su acceso.
Actor	Usuario
Prioridad	Alta
Entrada	Token de sesión activo
Salida	Confirmación de cierre de sesión, invalidación del token, limpieza de sesión del lado del servidor

Tabla 3 Requerimiento funcional 3
RF-03 Recuperación de contraseña
Descripción	El sistema debe permitir que los usuarios recuperen su contraseña mediante un proceso de verificación.
Actor	Usuario
Prioridad	Media
Entrada	Email del usuario registrado
Salida	Enlace de recuperación enviado al email, token temporal de reset válido por 24 horas, confirmación de envío

 
Tabla 4 Requerimiento funcional 4
RF-04 Gestión de roles del sistema

Actor	Administrativo
Prioridad	Alta
Entrada	Nombre del rol, lista de funcionalidades/permisos asociados, descripción del rol
Salida	ID del rol creado/actualizado, confirmación de creación, lista completa de roles del sistema

Tabla 5 Requerimiento funcional 5
RF-05 Control de acceso según rol

Actor	Sistema
Prioridad	Alta
Entrada	Token de usuario, ID de funcionalidad solicitada
Salida	Boolean indicando acceso permitido o denegado, lista de funcionalidades disponibles para el rol, mensaje de error si aplica
